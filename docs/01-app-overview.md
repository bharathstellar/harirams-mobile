# 1) App Overview

## Purpose of the App

Harirams Mobile is a hotel operations app for front-desk and admin teams. It supports the complete booking lifecycle:
- room selection
- customer details capture
- booking creation
- check-in and proof capture
- checkout and pending collection
- admin-level revenue and occupancy monitoring

## Target Users

- **Staff / Manager**
  - Create and update bookings
  - Perform guest check-in and checkout
  - Manage pending payments
- **Admin**
  - View current/future/past bookings
  - Cancel future bookings
  - Monitor occupancy and revenue
  - Access booking proofs

## Key Features

- Role-based login and dashboard routing
- Date-based available room selection
- Multi-step booking wizard with validation
- Document/proof capture (camera/gallery) and upload
- Check-in flow with optional vehicle proof
- Checkout flow with pending and misc charge handling
- Admin analytics (today/week/month/total revenue, payment mode split, occupancy)
- Search + pagination in booking lists

## Platforms

- **Android**: fully targeted and actively used (back button behavior handled in screens).
- **iOS**: supported through Expo + React Native stack.
- **Web**: Expo web script exists; app is primarily mobile-focused.
